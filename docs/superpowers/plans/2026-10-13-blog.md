# Blog Section Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a bilingual (RO/EN) blog to the static site: two listing pages, one published article in both languages, a copy-ready template, nav/footer/sitemap integration and a README recipe.

**Architecture:** Plain HTML files, one per page, sharing `css/style.css`. Listing pages are hand-maintained lists of cards. Article pages reuse the single-column document layout. No build step, no JavaScript.

**Tech Stack:** HTML5, CSS3, Netlify static hosting. Verification with `python3 -m http.server`, `curl`, `xmllint` (sitemap), `grep`, and a tiny inline Python tag-balance check (macOS `tidy` is a 2006 build that rejects HTML5 tags, so it is not used).

**Spec:** `docs/superpowers/specs/2026-10-13-blog-design.md`

## Global Constraints

- No build step, no JavaScript, no new dependencies, no new fonts, no new CSS tokens.
- Every RO page has an EN twin; `<head>` carries `hreflang` ro + en; `sitemap.xml` carries ro, en and x-default (→ ro) alternates.
- Blog pages reference shared assets with absolute paths: `/css/style.css`, `/favicon.svg`.
- Slugs: lowercase ASCII, hyphen-separated, diacritics stripped. EN slug is a translation.
- Dates: `<time datetime="YYYY-MM-DD">` with text "13 octombrie 2026" (RO) / "13 October 2026" (EN).
- `googlecaf98bf648c2b375.html` is never edited.
- Commit after every task, on branch `dev`, message ends with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.
- The EN article text is Claude's translation; the commit message and the final report must say it is a draft for Bianca's review.

## Review Focus

1. **Phone width (390px):** the article column, the CTA box and the listing cards must not overflow horizontally. Covered by Task 6 step 3.
2. **Nav wrap on narrow screens:** adding a 4th item ("Blog") must still wrap cleanly under the brand, not overlap. Covered by Task 6 step 3.
3. **Nav on the homepage:** "Blog" is an absolute link while the other items are `#anchors`; clicking it from `/` must land on `/blog/`, and clicking "Despre" from `/blog/` must land on `/#despre`. Covered by Task 5 step 4.
4. **Reciprocal hreflang:** each blog page's EN/RO alternate must point to a file that exists and that points back. Covered by Task 6 step 2.
5. **Template served but not indexed:** `/docs/blog-template.html` must return 200 (so a copy-paste is easy to preview) and carry `noindex`. Covered by Task 4 step 3.

from html.parser import HTMLParser
VOID = {'meta','link','img','br','hr','input','source','path','rect','circle'}
class P(HTMLParser):
    def __init__(s): super().__init__(); s.stack=[]; s.errors=[]
    def handle_starttag(s,t,a):
        if t not in VOID: s.stack.append((t,s.getpos()[0]))
    def handle_endtag(s,t):
        if t in VOID: return
        if not s.stack or s.stack[-1][0]!=t:
            s.errors.append(f'line {s.getpos()[0]}: </{t}> but open is {s.stack[-1] if s.stack else None}')
        else: s.stack.pop()
for f in ['blog/index.html', 'blog/executarea-silita-a-pensiei-de-intretinere.html']:
    p=P(); p.feed(open(f).read())
    if p.stack: p.errors.append(f'unclosed: {p.stack}')
    print(f, 'OK' if not p.errors else p.errors)
EOF
